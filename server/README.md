# 햄스터 아레나 서버 (전파폭탄 · 햄볼 대난투 · 마네킹 복싱 · 인생 시뮬레이션)

팀별 Claude 코치 챗으로 봇 페르소나를 정하고, 관리자가 버튼을 누르면 라운드가 시작되어 모든 브라우저에 생중계됩니다.

```bash
npm install
node server.js            # http://localhost:3000 — 관리자(/admin) 비번은 admin, 이 PC에 로그인된 claude CLI 계정으로 코치 실행
MOCK=1 node server.js     # 코치 없이 UI만 확인
```

- `/` 참가자: 팀 이름+비밀번호로 입장(처음 쓰는 이름이면 자동 생성) → 코치와 대화 → 페르소나 저장 → 경기 생중계·점수판
- `/admin` 관리자: 팀·페르소나 목록, **종목 전환**(전파폭탄 → 햄볼 대난투 → 마네킹 복싱 → 인생 시뮬레이션), **라운드 시작**, 속도 1/2/4×, 점수 초기화, 팀 삭제
- 종목마다 코치 규칙·페르소나 도구·엔진이 따로 (`game.js` 전파폭탄, `sumo.js` 햄볼 대난투, `boxing.js` 마네킹 복싱, `life.js` 인생 시뮬레이션). 페르소나는 종목별로 저장되고 점수판은 공유.
- 마네킹 복싱은 1대1 **토너먼트**: 라운드 시작마다 짝지어 붙이고 승자끼리 다시(홀수면 부전승), N-1경기 끝에 우승자. 3라운드×30초, 다운 3번/10카운트 KO 아니면 판정(무승부 없음). 승리 3점 + 다운 뺏을 때마다 1점. 실력은 모두 같고 팀은 스타일·몸 재질·장갑/트렁크 색·대사만 정한다(대회 전에 컨셉 확정, 이후 그대로).
- 햄볼 대난투 성격은 코치가 짓는 **규칙(스탯) 목록** — 이름 + 조건(9종) + 행동(7종) + 가중치. 가중치 합 3 초과 시 비례 축소(상호 보완), 매 순간 조건 맞는 규칙 중 가중치 큰 것이 실행.
- 인생 시뮬레이션: 팀은 햄스터 한 명의 **성격을 마크다운 문서**로 코치에게 보내 제출(코치는 고쳐 쓰지 않고 그대로 저장). 관리자가 "미션 배정 · 성격 작성 30분 시작"을 누르면 팀마다 미션(한 줄에 하나, 균등·무작위)이 붙고 30분 뒤 챗이 잠김. "N번째 인생 시작"마다 모든 팀이 **같은 대본**(관리자 페이지 텍스트 영역, `12: 역대급 한파` 한 줄 = 한 해, 기본 1~80세 80줄 내장)을 산다: 라운드 시작 때 팀마다 Claude 호출 2회(인생 시뮬 + 심판)로 미리 계산하고 10분(`LIFE_SEC`) 동안 나이순으로 재생. 대본·판정은 참가자와 코치에게 비공개. 미션을 달성한 인생마다 1점, 총 6번 환생, 인생이 끝나면 다시 성격을 고칠 수 있음. 동시 호출 수 `SIM_PAR`(8).
- 환경변수: `PORT`(3000) `ADMIN_PW`(admin) `MODEL`(haiku) `MOCK=1`(Claude 없이 키워드로 성향 추정)
- 데이터는 `data.json` 한 파일. 코치 호출 사용량은 `data-usage.jsonl`에 한 줄씩, 합계와 계정 사용량 창은 관리자 페이지에 표시. 팀이 8팀을 넘으면 한 라운드에 여러 경기를 자동으로 나눠 돌립니다.
- `npm test` 로 엔진·API 자체 점검.
